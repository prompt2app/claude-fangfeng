# 如何注册一个美区 Apple ID(无需信用卡)

> 原文地址：[https://claucc.net/articles/apply-us-apple-id](https://claucc.net/articles/apply-us-apple-id)　·　更多教程见 [claucc.net](https://claucc.net)

想下小火箭、订阅美区的 App,第一步都是要有一个**国家/地区为「美国」的 Apple ID**。这篇教你用一个全新邮箱从零注册,**不用信用卡、不用美国地址**,每步配示意图,照着点就行。

① **备邮箱·号码**（新邮箱 + 收码手机） → ② **网页注册**（地区选美国） → ③ **双重验证**（邮箱码 + 短信码） → ④ **iPhone 登录**（切到美区号即可）

*整条路四步:备料 → 注册 → 验证 → iPhone 登录*

> [!TIP]
> **关键点先说**:注册时国家/地区选**美国**就行,**不用信用卡、不用填美国地址**;在 iPhone 上通过「设置 → 头像 → 媒体与购买项目」切换成这个美区号即可。要下**付费**的小火箭,再给账户充点美区余额(支付宝买礼品卡)就行。

## 动手前先备好

| 准备项 | 要求 | 说明 |
| --- | --- | --- |
| 一个新邮箱 | 没注册过 Apple ID | QQ 邮箱、Gmail、Outlook 都行,只要没绑过苹果账号。 |
| 能收短信的手机号 | 可用 | **中国大陆号码就行**(用来收双重认证验证码),一个号别绑太多苹果账号。 |
| 美国地址 / 信用卡 | **不需要** | 注册美区号**不用**填美国地址、也**不用**信用卡。要下付费 App 时,充点美区余额即可(支付宝买礼品卡)。 |

## 第一步:网页注册 Apple ID

#### 1. 打开注册页

浏览器访问 `appleid.apple.com` → 点 **「创建您的 Apple ID」**。

#### 2. 填基本信息

填英文名字、姓氏;**国家/地区选 United States(美国)**;填出生日期。

#### 3. 填邮箱和密码

用刚才那个没绑过苹果的邮箱当 Apple ID,设一个密码(要有大小写+数字)。

#### 4. 填手机号

填一个能收短信的手机号,用于双重认证。

> *示意界面（appleid.apple.com）*：
>
> 创建您的 Apple ID
>
> 国家/地区
>
> United States　▾
>
> Email(即 Apple ID)
>
> your-new-mail@qq.com
>
> 电话号码
>
> +86 用于收验证码
>
> 继续

*图 1:注册页——国家/地区一定要选 United States(示意)*

## 第二步:完成双重验证

#### 1. 邮箱验证码

苹果给你邮箱发一封验证码,回去把码填进来。

#### 2. 短信验证码

手机会收到一条短信验证码,填进去。

#### 3. 创建成功

两个码都过了,Apple ID 就注册好了。这时它已经是**美国区**的账号。

> [!WARNING]
> 验证码有**时效**(几分钟),收到就赶紧填,别去忙别的。提示"该号码已被使用"就是这个手机号绑的苹果账号到上限了,换个号。

## 第三步:在 iPhone 上登录美区号

账号注册好了,接下来在 iPhone 上把 App Store 切换成这个美区号登录就行。**不需要绑信用卡、也不需要填美国地址**——付款方式选「无」即可(如果没看到「无」这个选项,见下一节)。

#### 1. 先退出当前 App Store 账号

打开 **「设置」** → 点**最上面的头像(你的 Apple ID)** → 往下找到并点 **「媒体与购买项目」** → 点 **「退出登录」**。  
(这样只退出 App Store / 购买账号,**不动 iCloud**,照片、通讯录都不受影响。新版 iPhone 在 App Store 里已经找不到退出按钮,要走这个渠道。)

#### 2. 登录新的美区号

就在 **「媒体与购买项目」** 里点**登录**(或打开 **App Store** 点右上角头像),输入刚注册的**美区 Apple ID 和密码**登录。

#### 3. 过首次使用提示

如果提示"此 Apple ID 尚未在 App Store 使用过" → 点**继续** → **同意条款**即可。地区显示 **美国** 就对了。到这就能下**免费** App 了。

> | 项目 | 说明 |
> | --- | --- |
> | 👤 你的 Apple ID | 最上面 |
> | 媒体与购买项目 | 点这里 › |
> | → 退出登录 | 切换账号 ✓ |
>
> 从这里切 App Store 账号，不影响 iCloud

*图 2:退出 / 切换 App Store 账号走「设置 → 头像 → 媒体与购买项目」*

## 付款方式:怎么选「无(None)」

这是最多人卡住的一步。先说结论:**苹果官方至今允许把付款方式设为「无」**,官方文档原话是 "*You can also choose None. You won't be charged until you make a purchase*."(你也可以选择「无」,在你真正购买前不会扣款)。所以**不需要绑信用卡**。

但很多人会遇到:**选项里就是没有「无 / None」**。这不是政策变了,而是触发了下面某个条件——对症解决就会出现:

| 「无」不出现的原因 | 怎么解决 |
| --- | --- |
| **IP 和账号地区对不上**(最常见) | 注册 / 设置美区号时,**必须挂着美国 IP**。用国内网络去操作美区账号,苹果会判定地区不符而收起「无」。挂上住宅节点再试。 |
| **账号是「改地区」改过来的** | 改地区时苹果**强制要求先填一个有效付款方式**。改完成功后,再回到付款设置里就能改成「无」。**所以最省事的是一开始就注册美区号,别注册别的区再改**。 |
| **有未付款项 / 欠款** | 购买历史里有未完成的账单,先付清。 |
| **有自动续订的订阅** | 存在订阅时苹果要求保留付款方式。先取消订阅,再改「无」。 |
| **在家人共享群组里** | 家庭共享由组织者统一付款,退出家庭共享后才能改。 |
| **首次使用 App Store 的验证** | 少数账号首次使用时会被要求先验证一次付款方式。可先充值礼品卡余额,或验证后再改回「无」。 |

> [!WARNING]
> **八成的人是第一条**。没挂美国 IP、或者挂的是机房 IP 去注册美区号,不但「无」不出现,还容易直接注册失败。**先确认出口是美国住宅 IP 再动手**,见 [注册前环境自检](ip-quality-check.md)。

如果实在调不出「无」,还有一条稳妥的路:**直接充值美区礼品卡余额**。有余额后,苹果通常就不再纠缠付款方式,而且下付费 App 本来也要余额——见 [没有信用卡也能给苹果账户充美元余额](apple-giftcard-topup.md)。

## 注册好之后

- **充余额**:要下付费 App(比如小火箭)或订阅,给账户充点美元余额即可,支付宝就能买,见 [没有信用卡也能给苹果账户充美元余额](apple-giftcard-topup.md)。
- **下小火箭**:有了美区号 + 余额,就能装小火箭了,见 [苹果手机怎么下载小火箭](iphone-download-shadowrocket.md)。
- **记好账号密码**和双重认证的手机号,以后更新 App、换设备都要用。

## 常见问题

| 现象 | 原因 / 解决 |
| --- | --- |
| App Store 里找不到「退出登录」 | 新版 iPhone 已把它移走。走 **设置 → 最上面头像 → 媒体与购买项目 → 退出登录** 来切换 App Store 账号。 |
| 下小火箭提示要付款 / 买不了 | 小火箭是付费 App,先给美区号**充点余额**(支付宝买礼品卡)再买,见 [充美元余额教程](apple-giftcard-topup.md)。 |
| 付款方式里**没有「无 / None」** | 多半是**没挂美国 IP**,或这个号是改地区改过来的(改地区必须先填一次付款方式)。逐条对照 [付款方式怎么选「无」](#付款方式怎么选无none)。 |
| 提示"该电话号码已被使用" | 这个手机号绑的苹果账号到上限了,换一个号收验证码。 |
| 邮箱说已注册过 Apple ID | 换一个**从没绑过苹果**的新邮箱。 |
| 后来想改地区却改不了 | 账号有余额/订阅/未完成的购买时改不了地区。全新号注册时直接选好美国就行,别注册成别的区再改。 |
