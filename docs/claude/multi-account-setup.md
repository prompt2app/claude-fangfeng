# 从 0 配好第一个隔离环境

> 原文地址：[https://claucc.net/articles/multi-account-setup](https://claucc.net/articles/multi-account-setup)　·　更多教程见 [claucc.net](https://claucc.net)

「一店一 IP」「一号一指纹」的道理你已经听过很多遍了。这篇**不讲道理,只讲怎么做**:从零开始,把第一个隔离环境跑通,然后告诉你怎么扩到十几个号还不乱。外贸多店铺、社媒矩阵通用。

> [!TIP]
> **先做一个,跑通了再复制**。新手最常见的失败是一上来同时配八个环境,配到一半自己都记不清哪个是哪个。**第一个务必单独配、单独验、单独用几天**。

## 要准备什么

| 东西 | 要求 | 说明 |
| --- | --- | --- |
| **独享住宅 IP** | 一个号一条,**不共用** | 共享 IP 上别人出事你连坐,做多账号等于白做 |
| **指纹浏览器** | 支持每环境单独填代理 | AdsPower / 比特 / HubStudio 均可,思路一样 |
| **独立邮箱** | 一个号一个 | 邮箱交叉是最硬的关联证据之一 |
| **独立收款 / 支付** | 尽量一号一个 | 见下面「绝对不能共用的四样」 |

## 七步配好第一个环境

#### 1. 先想好命名规则

动手前定好名字怎么起,以后不会乱。建议 **平台-序号**:`IG-01`、`Amazon-US-01`、`TK-03`。**指纹浏览器环境名、IP 备注、邮箱前缀全用同一个名字**,这样一眼能对上。

#### 2. 拿到这个号专属的代理参数

IP 服务商会给你一组:**SOCKS5 / 主机 / 端口 / 账号密码**。记下它属于哪个号,**这一组以后只给这一个号用**。

#### 3. 新建一个指纹浏览器环境

用第 1 步定好的名字命名。指纹保持**默认固定**,别开"每次随机"——真实设备的指纹是不变的。

#### 4. 把代理填进去并检测

代理类型选 **SOCKS5**,填那四个参数,点「检测代理」。要看到**连接成功 + 目标国家 + 住宅类型**。检测不通过多半是没开 TUN,见 [这一节](adspower-socks5-setup.md)。

#### 5. 时区设成跟随 IP

打开「基于 IP 匹配时区」。这一步别省,时区和 IP 对不上是很明显的异常。

#### 6. 登录前先验一遍

**在这个环境窗口里**打开 `ippure.com`,确认住宅、风险分绿、地域对、无泄露。完整清单见 [切号 / 登录前环境自检](switch-account-checkup.md)。

#### 7. 全绿了,再登录 / 注册账号

**顺序不能反**。先登号再验环境,万一有问题这个号已经被记录了。

## 给每个号建一份「环境档」

这是新手最容易跳过、后期最后悔的一步。号一多,你会完全记不清谁配了哪条 IP。用表格或备忘录记下来即可:

| 项目 | 说明 |
| --- | --- |
| 环境名 | IG-01 |
| 对应账号 | 该 IG 账号的用户名 |
| 代理 | 分配给它的那一条(记端口即可) |
| 注册邮箱 | 该号专用邮箱 |
| 注册时间 | 2026-08-26 |
| 支付方式 | 该号专用的那个 |
| 状态备注 | 正常 / 风险分变高 / 已停用 |

*图:一号一行,出问题时能立刻查出是哪一层串了*

> [!WARNING]
> **这份档案别和账号密码存在一起,也别存在会被同步到公共云的地方**。它等于你整个矩阵的地图。

## 绝对不能共用的四样

IP 和指纹隔离做到满分,只要这四样交叉,平台照样能把号串起来——**而且这些是你主动提交的,比 IP 硬得多**:

| 不能共用 | 为什么 | 怎么做 |
| --- | --- | --- |
| **收款 / 支付账号** | 一张卡付多个店 / 多个号广告费,等于签名承认是同一人 | 一号一个;做不到至少把重要号和高风险号分开 |
| **实名信息**(执照 / 法人 / 身份证) | 外贸多店最致命的一条,直接实名级关联 | 不同主体分开,别图省事全用一套 |
| **邮箱 / 手机号** | 找回方式交叉是极强的关联证据 | 一号一邮箱;二次验证别都绑同一个号码 |
| **地址与素材** | 同一退货地址、同一批产品图 / 简介,内容层面就能聚类 | 地址分开,素材做出差异,别整批复用 |

> [!CAUTION]
> **还有一条几乎人人踩:自己的号之间互相关注、互相点赞、互相下单**。这是主动告诉平台"我们是一伙的",比任何技术手段都直接。矩阵号之间要当陌生人。

## 从 1 个扩到 10 个

#### 1. 第一个用稳几天再复制

确认它能正常登录、不弹验证、没被限制,再配第二个。

#### 2. 一次加一两个,别一批开十个

短时间冒出一大批新号本身就是异常信号,分散着来。

#### 3. 每加一个就更新环境档

当场记,别想着"回头一起补",一定补不全。

#### 4. 操作节奏错开

别所有号都在同一时段、用同样的节奏干同样的事。行为层的雷同一样会被聚类。

#### 5. 每月抽查环境

挑几个跑一遍自检,看风险分有没有变高。变高了换一条 IP,别硬用。

> [!TIP]
> **号多了之后建议把指纹浏览器放到境外机器上跑**。本机网络一波动会影响一堆环境,而且十几个环境同时开很吃内存。用一台境外 VPS / 云电脑更省心。

## 常见问题

- **能不能几个号共用一条 IP**?技术上可以,风险上不建议——共用就是在制造关联点。真要省成本,**把最重要的号单独隔离**,别让它和其他号挤一起。
- **已经混着用了怎么办**?别急着全部推倒。先把**最有价值的那个号**迁到干净的独立环境,其余的逐步分开。
- **指纹浏览器要花钱吗**?多数有免费额度,够个人开几个环境。要选的话只看三条:能不能每环境单独填代理、时区能不能跟随、指纹是否固定不变。
- **用虚拟机代替指纹浏览器行吗**?行,而且更彻底,但成本高得多。十几个号用虚拟机不现实,指纹浏览器是性价比最高的方案。
