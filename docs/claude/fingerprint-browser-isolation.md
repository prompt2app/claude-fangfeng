# 指纹浏览器 + 独享住宅 IP:多号隔离怎么做

> 原文地址：[https://claucc.net/articles/fingerprint-browser-isolation](https://claucc.net/articles/fingerprint-browser-isolation)　·　更多教程见 [claucc.net](https://claucc.net)

在 [封号机制](claude-anti-ban.md) 那篇里讲过一个结论:**设备指纹的权重比 IP 高得多**。所以「一个号配一个 IP」只做对了一半——同一台电脑上开十个号,就算每个号换 IP,指纹一样,平台照样知道是同一个人。这篇讲另一半怎么做。

> [!TIP]
> **只有一个账号的人不用看这篇**。一个号老老实实用一个独立浏览器 Profile 就够了(例外:这台电脑上以前有号被封过,重注时就算只有一个号也要上指纹浏览器,见 [清理设备指纹](claude-clean-fingerprint-reregister.md))。指纹浏览器是给**多账号**准备的——外贸多店铺、社媒矩阵、或者手里有好几个 AI 账号。

## 先搞清楚要隔离的是什么

平台把多个账号判成「同一个人」,靠的是这几条线索连起来的关联图谱。少断一条,隔离就是漏的:

| 线索 | 怎么断开 | 只换 IP 的话 |
| --- | --- | --- |
| **出口 IP** | 一号一个独享住宅 IP | ✓ 断开了 |
| **设备指纹** Canvas / WebGL / 字体 / 音频 | 指纹浏览器,每个环境一套独立指纹 | ✗ **还是同一张脸** |
| **Cookie / 登录态** | 每个环境独立的存储空间 | ✗ 混在一个浏览器里就是串的 |
| **时区 / 语言** | 跟随各自 IP 所在地 | ✗ 十个号都是北京时区 |
| **支付信息** | 一号一张卡 / 一个支付账号 | ✗ 同一张卡把号全串起来 |

> [!CAUTION]
> **支付信息这条最容易被忽略**。十个环境做得再干净,最后都用同一张卡付款,等于亲手把它们连成一串。

## 指纹浏览器是什么、怎么选

指纹浏览器就是能开出多个**互相隔离的浏览器环境**的工具:每个环境有自己的 Canvas / WebGL 指纹、字体列表、时区、UA、Cookie 存储,互相看不见。常见的有 HubStudio、AdsPower、比特浏览器等,功能大同小异。

选的时候真正该看的只有三条:

- **能不能给每个环境单独填代理**——这是核心功能,不支持的直接排除。
- **时区 / 语言能不能跟随代理 IP 自动设**——不能的话你得手动一个个改,量一大就会漏。
- **指纹是不是每个环境固定不变**——每次打开都换一套随机指纹反而更可疑,真实用户的设备是不会变的。

## 把独享 IP 绑进每个环境

我们给多账号客户提供的是**每个账号一个独享住宅出口**,以 socks5 的形式给你,一个环境填一个:

| 项目 | 说明 |
| --- | --- |
| 代理类型 | SOCKS5 |
| 主机 | 你的专属入口域名 |
| 端口 | 分配给你的端口 |
| 用户名 / 密码 | 每个环境一组,互不相同 |

*图:指纹浏览器里每个环境的代理配置(具体参数以服务商提供的为准)*

#### 1. 新建环境

在指纹浏览器里新建一个浏览器环境,起个能认出来的名字(如「IG-01」)。

#### 2. 填代理

代理类型选 **SOCKS5**,填入我们给你的那一组主机 / 端口 / 账号密码。**一个环境一组,不要复用**。

#### 3. 点「检测代理」

工具一般都有这个按钮。要看到:出口是**美国**、类型是**住宅**。不通先看下面那节。

#### 4. 时区语言设成跟随

打开「基于 IP 匹配时区」之类的开关。手动设也行,但一定要和该环境的 IP 所在地对得上。

#### 5. 先验环境再登号

打开环境,访问 `ippure.com` 确认住宅 + 风险分绿 + 无泄露,**然后**才登录账号。见 [环境自检](ip-quality-check.md)。

## 最常见的坑:在国内直接填 socks5 连不上

> [!CAUTION]
> 指纹浏览器**自己去拨这个 socks5,不会经过你的 clash**。代理链不会自动发生——你开着 clash 不等于指纹浏览器就走了 clash。

结果就是:它从你的国内网络裸连一个境外地址,大概率连不上,工具里报「代理失败 / 检测不通过」。这不是账号密码填错了。

**两种解法,选一个**:

| 做法 | 怎么做 | 说明 |
| --- | --- | --- |
| **开 TUN** | 在 clash / Stash 里打开 TUN(虚拟网卡) | 最简单。开了之后指纹浏览器的流量也会被接管,socks5 就能拨通 |
| **把指纹浏览器放到境外机器上** | 用一台境外 VPS / 云电脑跑指纹浏览器 | 多账号量大时更稳,也省得本机网络波动影响一堆环境 |

另外:如果你要连的服务用了 **80 / 443 以外的端口**,住宅网关一般不放行,这种得单独给你配成走节点直出——[告诉我端口](https://claucc.net/contact),服务端加条规则就行,你不用换配置。

## 日常怎么用才不白配

#### 1. 一个环境只登一个号

别在同一个环境里切来切去登两个号,那等于没隔离。

#### 2. 环境和 IP 长期绑死

「IG-01」这个环境永远配这一个 IP。真实用户不会天天换城市,别轮换。

#### 3. 别频繁清指纹

指纹固定才像真设备。有些人习惯性「重置环境」,反而制造异常。

#### 4. 支付也要分开

能一号一卡最好;做不到至少别让重要的号和高风险的号共用一个支付账号。

#### 5. 定期抽查

每月挑几个环境跑一遍 [环境自检](ip-quality-check.md),看风险分有没有变高。变高了换一条 IP,别硬用。

## 几个容易误会的点

- **指纹浏览器不能救已经脏了的号**。它防的是「新号被关联」,不是「老号洗白」。被封的号该清理重注的看 [清理设备指纹重新注册](claude-clean-fingerprint-reregister.md)。
- **登录活动里的城市可能不刷新**。有些平台(如 IG)的「登录活动」显示的是**会话创建时**记录的位置,你中途挂上代理它不会变。要更新得退出重登。
- **共享 IP 再便宜也别用在多账号上**。几百人共用一个出口,别人出事你连坐,这跟你花力气做隔离是反着的。
- **做到这一步不等于随便造**。隔离解决的是「别被连坐」,不解决「行为本身异常」——批量、高频、机械化的操作照样会被单独盯上。
