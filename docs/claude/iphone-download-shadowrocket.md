# 苹果手机怎么下载小火箭(Shadowrocket)

> 原文地址：[https://claucc.net/articles/iphone-download-shadowrocket](https://claucc.net/articles/iphone-download-shadowrocket)　·　更多教程见 [claucc.net](https://claucc.net)

小火箭在中国区 App Store 里搜不到、下不了——它只在美区(及其它外区)上架,而且是一款**付费 App(约 $2.99)**。所以要装它,得用一个美区 Apple ID 登录 App Store。这篇每步配示意图,小白照着点也能下下来。

① **备美区 ID**（地区=美国 + 有余额） → ② **换登录**（App Store 登美区号） → ③ **搜索**（Shadowrocket） → ④ **购买下载**（从余额扣 $2.99）

*整条路四步:备号 → 换登录 → 搜索 → 下载*

> [!TIP]
> **先记住一句话**:你只需要换 **App Store 里登录的账号**,不用动「设置 → iCloud」那个 Apple ID。所以你的照片、通讯录、微信数据都不受影响,放心操作。

## 第一步:退出 App Store 当前账号

#### 1. 打开「设置」

点桌面的 **「设置」**,再点**最上面的头像(你的 Apple ID)**。

#### 2. 进「媒体与购买项目」

在里面往下找到并点 **「媒体与购买项目」**。(新版 iPhone 在 App Store 里**已经找不到退出按钮**,要走这个渠道。)

#### 3. 退出登录

点 **「退出登录」**,把现在的中国区账号退出来。这只退出 App Store / 购买账号,**不动 iCloud**。

> [!CAUTION]
> 从「**设置 → 头像 → 媒体与购买项目 → 退出登录**」退,只退 App Store 的购买账号;**别点「设置 → 头像」页顶部那个红色「退出登录」**——那个退的是整个 iCloud,会影响照片、通讯录、查找。

## 第二步:登录美区 Apple ID

#### 1. 登录美区号

就在「媒体与购买项目」里点**登录**(或打开 App Store 点右上角头像),输入**美区 Apple ID** 的邮箱和密码 → 登录。

#### 2. 首次登录的提示

如果弹「此 Apple ID 尚未在 App Store 使用过」,点**检查 / 继续**,按提示:地区确认 **美国**、同意条款即可(**不用设付款方式、不用填美国地址**)。

#### 3. 确认已是美区

登录成功后,App Store 界面会变成英文、显示美区榜单。

*图 3:用美区 Apple ID 登录 App Store(示意)*

## 第三步:搜索并下载小火箭

#### 1. 去搜索

点 App Store 底部的 **「搜索」**,输入 `Shadowrocket`。

#### 2. 认准那只火箭

找图标是一只**火箭**、开发者写着 **Shadow Launch Technology Limited** 的那个,别下错山寨。

#### 3. 点价格购买

点右侧的价格($2.99)→ 变成「购买」再点一次 → 用**面容 ID / 密码**确认。钱从你的美区**余额**里扣。

#### 4. 等它下载完

下载完成后,桌面就出现小火箭图标了。

## 装好之后

- **导入订阅**:打开小火箭,把你的**订阅链接**导入即可开始用。详细步骤见 [iPhone 小火箭配置教程](https://claucc.net/教程/ios-shadowrocket)。
- **可以切回原账号**:下载完后,你可以在「设置 → 头像 → 媒体与购买项目」退出美区号、登回中国区账号,已装好的小火箭**不会消失**。只是以后**更新**小火箭时,需要再登一次美区号。

## 常见问题

| 现象 | 原因 / 解决 |
| --- | --- |
| 搜不到小火箭 | 你还在**中国区**。确认 App Store 头像页登录的是**美区 Apple ID**、界面已变英文。 |
| 提示"尚未在 iTunes Store 使用过" | 首次登录正常提示。点继续 → 确认地区美国 → 同意条款 → 付款方式选**无(None)**。 |
| "无法完成购买 / 需要付款方式" | 余额不足,或没设付款方式。**充点余额**即可([礼品卡充值](apple-giftcard-topup.md)),付款方式仍可选无。 |
| 下到了长得像的别的 App | 认准**火箭图标 + 开发者 Shadow Launch Technology Limited**,别下山寨代理。 |
