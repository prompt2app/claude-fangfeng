# 没有信用卡,也能给苹果账户充上美元余额

> 原文地址：[https://claucc.net/articles/apple-giftcard-topup](https://claucc.net/articles/apple-giftcard-topup)　·　更多教程见 [claucc.net](https://claucc.net)

想用 App Store 里的付费应用或订阅(比如各种 AI 工具),却卡在没有国外银行卡?其实不需要外币信用卡——用支付宝买一张美区 Apple 礼品卡,人民币付款,兑换进账户就是美元余额。下面把整条路拆成 9 步,并给出几个可选的购卡渠道——入口偶尔会变,但方法一直有效。

> [!CAUTION]
> **2026 年 11 月更新**:近期不少人反馈,**只靠礼品卡余额、没有绑定任何付款方式**的美区 Apple ID,充值或付款时会**直接被拒**,或**付款后被要求做身份验证(KYC)**。买卡前心里有数:**先买最小面额试通再加量**;遇到被拒别反复重试,被要求验证时别提交别人的证件或编造的资料(查出来 Apple ID 会被永久锁定,余额一起没)。用余额订阅 Claude 的完整处理办法见 [付款被拒 / 被要求身份验证怎么办](claude-subscription.md)。

## 先把思路捋清

整件事就三段,想明白了再动手就不会点懵:

- **第一段**:把支付宝的定位切到美国,解锁海外消费的入口。
- **第二段**:在里面买一张美区的苹果礼品卡,拿到一串兑换码。
- **第三段**:回到 iPhone,把这串码兑换进账户,变成余额。

> [!WARNING]
> **前提:先有一个「国家/地区 = 美国」的 Apple ID**。美区礼品卡只能充进美区账户。要是还没有,先把美区 ID 准备好再回来买卡,不然卡买回来喂不进去。

## 第一段:支付宝切定位到美国

### 1. 点左上角的城市

打开支付宝,盯着左上角,那里默认显示你现在所在的城市(比如南京)。点它。支付宝不少跨境服务是跟着定位走的,人在国内看到的就是国内那一套,我们先把定位挪一挪。

### 2. 把城市切到旧金山

进去后是城市和天气页面,上面有「国内」和「国际/港澳台」两个标签。切到「国际/港澳台」,在热门城市里找到**旧金山**,点它。选旧金山没别的讲究,就是让支付宝认为你在看美国这一边的服务。

### 3. 找到大牌礼卡入口

定位一切,支付宝首页会悄悄变样,多出一片新内容。往下翻一点,能看到一个**大牌礼卡**板块,点进去。

## 第二段:买美区苹果礼品卡

> [!WARNING]
> **渠道会变,要求不变**。下面几条路都有人在走,**入口时不时会调整**(比如 Pockyt 一度从支付宝内下架)。你不用死记某个入口,只要盯住三个硬要求:**①必须是 Apple Gift Card「US」**、**②能用人民币付**、**③拿到的是没被兑换过的新码**。哪条路满足就用哪条。

### 4. 选一个购买渠道

| 渠道 | 怎么走 | 怎么看 |
| --- | --- | --- |
| **支付宝内「大牌礼卡」** | 定位切美国后,首页往下翻找「大牌礼卡」板块,进去找带 Pockyt 的礼卡店 | 走支付宝担保,相对省心。**但入口时有调整,找不到属正常**,换下面的路 |
| **Pockyt 官网** | 浏览器打开 `shop.pockyt.io`,用支付宝扫码登录 / 付款 | 支付宝里找不到入口时的备选,流程和站内基本一样 |
| **闲鱼等二手平台** | 搜「美区 苹果礼品卡」,挑信誉好、销量高的卖家 | ⚠️ **风险最高**,务必看下面那段避坑 |
| **苹果美国官网** | `apple.com/us` 直接买,填收卡邮箱 | 最正规,但**要美国信用卡**——有卡的话就不用看这篇了 |

### 5. 注册 / 登录购买平台

第三方平台第一次用一般要注册,填一个能收邮件的邮箱,它会发验证码过来。**注意时效**(通常十分钟),收到就赶紧填,别先去忙别的。

### 6. 认准「Apple Gift Card US」

礼卡列表里亚马逊、eBay、Google Play 各种品牌都有。要找的是那张彩色苹果 logo、写着 **Apple Gift Card US** 的——**必须带 US**,这点最关键。买成别的区(日区、港区)的卡,充不进美区账户,而且一般不退。

### 7. 选面额,下单付款

第一次**别上来就充太多**,先拿个小额(比如 20 美元)把整条路跑通。购卡须知里通常会写明**此卡仅适用于美国的苹果账户**,确认没问题再下单,用支付宝付人民币。

### ⚠️ 从闲鱼等二手平台买,必看这段

> [!CAUTION]
> **最大的雷不是被骗钱,是账号被封**。价格明显低于面值的卡(比如 $100 的卡卖你 $80),很可能是盗刷来的「黑卡」。一旦拿它充值,苹果追查到后会**永久锁定你的 Apple ID 并扣掉余额**——号和钱一起没。

- **折扣太狠的一律不碰**。正规渠道通常也就 9 折上下,深折扣基本等于黑卡。
- **警惕「已被兑换」的码**。这是二手平台高频投诉:付了钱拿到一串早已用过的码。要求卖家**发货后当场兑换验证**,别拖到确认收货之后。
- **别脱离平台交易**。加微信私下转账 = 没有任何申诉依据,平台管不了。
- **先小额试**。第一次和新卖家交易,先买最小面额验证靠谱再加量。
- **留好聊天和付款记录**,万一要申诉能拿得出证据。

## 第三段:回 iPhone 兑换成余额

### 8. 兑换充值卡或代码

付完款会拿到一串礼品卡兑换码。回到 iPhone,打开「设置」点最上面头像进账户,或直接打开 App Store 点右上角头像,找到**「兑换充值卡或代码」**。把那串码填进去,或直接用摄像头扫卡面也行。

### 9. 余额到账

兑换成功后回到账户页,「账户余额」那一栏会实打实多出一笔(比如 20.00 美元),下面国家地区写着美国。到这,整套流程就走完了。

这笔余额用途很广:App Store 里的付费应用、订阅类工具、电子书、游戏内购都能直接用。美区 App Store 里那些你一直差一张卡的好东西,现在账户里有底气正常拿下了。

## 最容易踩的几个坑

| 坑 | 后果 / 怎么避 |
| --- | --- |
| Apple ID 地区不是美国 | 美区卡**喂不进去**,而且卡一般不退。买卡前先确认账号地区,见 [注册美区 Apple ID](apply-us-apple-id.md)。 |
| 买成了别的区的卡 | 日区、港区的卡充不进美区账户。**认准 Apple Gift Card「US」**。 |
| 贪便宜买到黑卡 | ⚠️ 最严重:**Apple ID 被永久锁定、余额清零**。折扣明显低于市场价的一律别碰。 |
| 拿到已被兑换的码 | 二手平台高频投诉。**当场兑换验证**,别先确认收货。 |
| 验证码过期 | 第三方平台的邮箱验证码通常只有十分钟,收到马上填。 |
| 找不到文中的入口 | 入口会调整,属正常。换本文列的其他渠道即可,方法本身没变。 |

## 几句真心话

第一次别贪多,**小额试水**,跑通了再加量。礼品卡一旦买了,按平台规则一般**不退不换**,下单前心里得有个数。

还有一句最重要的:**省那点折扣,不值得赌一个 Apple ID**。黑卡的代价是账号被永久锁定,你在这个号上买过的所有 App、订阅、余额全部一起没。宁可走正规渠道原价买。
