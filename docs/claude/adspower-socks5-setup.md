# AdsPower 指纹浏览器配合独享 socks5:完整配置

> 原文地址：[https://claucc.net/articles/adspower-socks5-setup](https://claucc.net/articles/adspower-socks5-setup)　·　更多教程见 [claucc.net](https://claucc.net)

新建一个 Chrome Profile 只能隔离 Cookie,**设备指纹还是同一张脸**。这篇讲怎么用 AdsPower 建一个真正独立的浏览器环境,两种接法都讲:**本地直连**(直接用你电脑上在用的代理订阅,不用额外买 socks5)和**独享 socks5**(一个环境一个 IP),并在登录账号前验证到位。

> [!TIP]
> **先说清楚谁需要这篇**。如果你只有**一个**账号,老老实实用一个独立 Chrome Profile 也能用。指纹浏览器解决的是两件 Profile 解决不了的事:**①指纹层面的隔离**(多账号防关联)、**②给单个环境单独挂代理**(不影响系统其他流量)。

## 为什么 Chrome Profile 不够

换一个 Profile,变的只有 Cookie 和登录态;而风控真正拿来认人的**设备指纹**一样没变——因为它读的是同一台电脑的硬件和系统特征:

| 风控读什么 | 换 Chrome Profile | 换 AdsPower 环境 |
| --- | --- | --- |
| Cookie / 登录态 | ✓ 隔离了 | ✓ 隔离了 |
| Canvas / WebGL 指纹 | ✗ **完全相同** | ✓ 每个环境一套 |
| 字体列表 / 音频指纹 | ✗ 相同 | ✓ 独立 |
| 时区 / 语言 | ✗ 跟随系统,全都一样 | ✓ 可跟随各自代理 IP |
| 出口 IP | ✗ 跟随系统代理,几个 Profile 共用一个 | ✓ **一个环境一个 IP** |

最后一行是重点:Chrome Profile **没法给单个 Profile 单独设代理**,它只能跟着系统走。而 AdsPower 是**一个环境填一个代理**,这才配得上"一号一 IP"。

背后的完整原理(为什么指纹权重比 IP 还高)见 [理解 Claude 为什么被封号](claude-anti-ban.md);多账号整体隔离方案见 [指纹浏览器 + 独享住宅 IP](fingerprint-browser-isolation.md)。

## 两种接法:先选对

AdsPower 接代理有两种方式。**大多数人用第一种就够了**,不需要另外准备 socks5:

|  | 方式一:本地直连 | 方式二:独享 socks5 |
| --- | --- | --- |
| AdsPower 里怎么填 | 代理选**不使用代理(本地直连)** | 每个环境填一组 socks5 参数 |
| 出口 IP | 就是你订阅的那个住宅 IP | 每个环境一个独立住宅 IP |
| 前提 | 电脑上的 代理客户端开着 **TUN(虚拟网卡)** | 另外开通独享 socks5 |
| 适合 | **一个账号**,或几个账号本来就共用一个 IP | **多个账号要互相隔离**、一号一 IP |

简单记:**只有一个号 → 方式一;要养多个号防关联 → 方式二**。指纹隔离两种方式都有,区别只在出口 IP 是不是每个环境各一个。

## 方式一:本地直连(用 代理订阅,不需要 socks5)

原理:环境里不填任何代理,浏览器按本机网络出去;而本机的流量被 代理客户端的 **TUN** 整体接管,于是这个环境的出口就是你订阅的美国住宅 IP。

#### 1. 先把 代理客户端开到 TUN 模式

在 Clash Verge / FlClash 里打开 **TUN(虚拟网卡)** 开关,出站模式保持**规则**。用你平时的浏览器打开 ippure.com,确认显示**美国 / 住宅**,再往下做。

#### 2. 新建环境,代理选「不使用代理」

点「新建浏览器」,在「代理设置」里选**不使用代理**(有的版本叫**本地直连 / No Proxy**)。不用填主机、端口和账号密码。

#### 3. 时区语言设成跟随 IP

和方式二一样,打开「基于 IP 匹配时区 / 语言」。AdsPower 检测到的是 TUN 出去的住宅 IP,会自动匹配到对应的美国时区。

#### 4. WebRTC 设成替换或禁用

在指纹设置里把 **WebRTC** 设成**替换**或**禁用**,别用「真实」,避免本机内网信息被网页读到。

#### 5. 保存、打开,按下文「先验环境」核对

在环境窗口里打开 ippure.com,IP 应该和第 1 步看到的一致(美国住宅),时区一致、无泄露,再登录账号。

> [!CAUTION]
> **必须开 TUN,只开「系统代理」不行**。指纹浏览器的内核不一定走系统代理,只开系统代理时它可能直接用国内网络出去,环境里显示的就是你的真实国内 IP。**每次打开环境前,先确认 代理客户端开着、TUN 开着**;客户端没开的时候千万别在环境里登录账号。

> [!TIP]
> **本地直连下,所有环境共用同一个出口 IP**。一个号用完全没问题;如果要同时养多个互相隔离的号,多个环境共用一个 IP 等于把它们串在一起,这时请用下面的方式二。

## 方式二:独享 socks5 —— 准备参数

独享 socks5 的服务商会给你**一组四个参数**。账号密码只给你自己用,不要和别人共用:

| 项目 | 说明 |
| --- | --- |
| 代理类型 | SOCKS5 |
| 主机(Host) | <入口域名> |
| 端口(Port) | <分配给你的端口> |
| 用户名 / 密码 | <你的专属账号> / <密码> |

*图:你会拿到的四个参数(具体数值以服务商给的为准)*

> [!CAUTION]
> **这组 socks5 只能在能连上外网的环境里用**。指纹浏览器是**自己去拨这个代理的**,不会经过你的 clash——所以在国内直接填,大概率连不通。往下看「代理检测不通过」那节,两种解法二选一。

## 第一步:装好 AdsPower

#### 1. 下载安装

去 AdsPower 官网下载对应系统的客户端(Windows / macOS 都有),注册一个账号登录。免费额度通常够个人用几个环境。

#### 2. 认准「浏览器环境」这个概念

AdsPower 里一个「环境」= 一个完全独立的浏览器:独立指纹、独立 Cookie、独立代理。**一个账号对应一个环境**,别在一个环境里登多个号。

## 第二步:新建环境并填入 socks5

#### 1. 新建环境

点「新建浏览器」,名字起得能认出来,比如 `Claude-01`。平台选项按默认即可。

#### 2. 代理类型选 SOCKS5

在「代理设置」里,代理方式选**自定义**,代理类型选 **SOCKS5**(不要选 HTTP,我们给的是 socks5)。

#### 3. 填四个参数

把主机、端口、用户名、密码依次填进去。注意**别把域名前面加 http**://,主机栏只填域名本身。

#### 4. 点「检测代理」

这是最关键的一步。要看到:**连接成功**、国家显示**美国**、IP 类型是**住宅(ISP/Residential)**。不通往下看第三步。

#### 5. 时区语言设成跟随 IP

把「基于 IP 匹配时区」之类的开关打开。AdsPower 会自动把环境时区设成代理 IP 所在地——这一步别省,时区对不上是很明显的异常信号。

> [!WARNING]
> **这个时区只管这个浏览器环境**。如果你还会用 **Claude / ChatGPT 的桌面 App**,或者 **Claude Code、Codex CLI** 这类命令行工具,它们读的是**系统时区**,指纹浏览器管不到——那就**还得把系统时区也改成美区**。否则同一个账号从两个渠道报出两个时区,自相矛盾反而更扎眼。

#### 6. 保存并启动

保存后点「打开」,会弹出一个独立的浏览器窗口。**以后这个账号的所有操作都在这个窗口里做**。

> [!TIP]
> **指纹参数不用自己调**。AdsPower 默认会给每个环境生成一套固定且合理的指纹,保持默认即可。**千万别开"每次启动随机指纹**"——真实设备的指纹是不会变的,天天变反而更可疑。

## 第三步:代理检测不通过怎么办

这是最高频的问题,而且**九成不是账号密码填错了**。原因是:AdsPower 自己去拨这个 socks5,**它的流量不经过你的 clash**——代理链不会自动发生。于是它等于从国内网络裸连一个境外地址,连不上。

| 解法 | 怎么做 | 适合谁 |
| --- | --- | --- |
| **开 TUN(推荐)** | 在 clash / Stash 客户端里打开 **TUN(虚拟网卡)** 开关,然后再点检测 | 绝大多数人。开了之后 AdsPower 的流量也会被接管,socks5 就能拨通 |
| **放到境外机器上** | 用一台境外 VPS / 云电脑跑 AdsPower | 账号多、要长期稳定的人;也省得本机网络波动影响一堆环境 |

> [!WARNING]
> 如果你要访问的服务用了 **80 / 443 以外的端口**,住宅网关一般不放行,这种需要单独配成走节点直出。[把端口告诉我们](https://claucc.net/contact),服务端加条规则即可,你不用改任何配置。

## 第四步:登录账号前,先验环境

顺序很重要:**先把环境验干净,再登录账号**。反过来做,万一环境有问题,号已经被记录了。

#### 1. 在 AdsPower 窗口里打开 ippure.com

注意是**在环境窗口里**打开,不是你日常浏览器。

#### 2. 逐项核对

IP 类型 **Residential(住宅)**、风险分 **绿色**、国家 **United States**、**无 DNS / WebRTC 泄露**。

#### 3. 核对时区

页面显示的时区应该和 IP 所在地一致。不一致就回去把「跟随 IP」打开。

#### 4. 全绿了,再注册 / 登录

确认无误后才开始注册账号。完整判读标准见 [注册前环境自检](ip-quality-check.md)。

| 项目 | 说明 |
| --- | --- |
| IP 类型 | Residential 住宅 ✓ |
| 风险分 | 绿色(0–25)✓ |
| 所在地 | United States ✓ |
| 时区 | 与 IP 一致 ✓ |
| DNS / WebRTC | 无泄露 ✓ |

*图:这五项全绿,才可以开始登录账号*

## 日常使用的几条铁律

#### 1. 一个环境只登一个号

在同一个环境里切换登录两个账号,等于没隔离。

#### 2. 环境和 IP 长期绑死

`Claude-01` 永远配这一个 IP,别轮换。真实用户不会天天换城市。

#### 3. 别删环境重建

删掉重建等于换了台新设备,已登录的账号会看到"设备变了"。有问题先加群问。

#### 4. 支付方式也要分开

多个号最后都用同一张卡付款,等于亲手把它们连成一串。

#### 5. 定期抽查

每月挑几个环境跑一遍自检,风险分变高了换一条 IP,别硬用。

## 常见疑问

- **本地直连和 socks5 怎么选**?只有一个号、平时就开着 代理客户端,用本地直连,不用额外花钱;要同时养多个号、每个号一个 IP,才需要独享 socks5。两种都能保住指纹隔离。
- **必须用 AdsPower 吗**?不是。比特浏览器、HubStudio 等同类工具配置思路完全一样——找到「代理设置 → SOCKS5」填四个参数即可。选型建议见 [这篇](fingerprint-browser-isolation.md)。
- **已经有 Chrome Profile 在用,要迁过来吗**?如果那个号一直没出问题、而且你只有一个号,不用折腾。**要开第二个号之前**再上指纹浏览器。
- **环境配好了,Claude 怎么登录**?用邮箱方式登录、不点 Google 快捷登录,桌面端和 Claude Code 也在这个环境里授权,步骤见 [用 AdsPower 指纹浏览器登录 Claude](claude-clean-fingerprint-reregister.md)。
- **指纹浏览器能救已经被封的号吗**?不能。它防的是「新号被关联」,不是「老号洗白」。被封后的正确做法见 [清理设备指纹重新注册](claude-clean-fingerprint-reregister.md)。
- **为什么不用免费的指纹浏览器**?可以用,但要确认它支持**每个环境单独填代理**且**指纹固定不变**,这两条不满足的直接排除。
