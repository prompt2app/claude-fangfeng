# Claude 被封号后,如何清理设备指纹、重新注册不再被封

> 原文地址：[https://claucc.net/articles/claude-clean-fingerprint-reregister](https://claucc.net/articles/claude-clean-fingerprint-reregister)　·　更多教程见 [claucc.net](https://claucc.net)

号被封了想重来,很多人直接在原来的设备、原来的网络上再注册一个,结果新号**很快又被封**。原因是 Anthropic 会把新号和旧号"关联"起来:它不只看账号,还看你这台设备、这个浏览器、这条网络长什么样。这篇按顺序把每一层都换干净,从换 IP 一直讲到注册新号、登录桌面端和 Claude Code、注册后怎么养号。**照着从上往下做就行,中途不用再去看别的文章**。

## 开始前:准备好这几样东西

整个流程大约 **40–60 分钟**。先把下面这些准备好,做到一半缺东西最容易出错:

| 要准备的 | 要求 | 怎么来 |
| --- | --- | --- |
| 一条新的美国住宅 IP | 和被封时用的那条**不是同一段** | 找你的 IP 服务商换一条不同段的,说明"号被封了要换段" |
| 代理客户端 | 电脑上装好 Clash Verge 或 FlClash,订阅已导入 | 你的代理订阅链接 |
| AdsPower 指纹浏览器 | 免费版就够一个号用 | AdsPower 官网下载(Windows / Mac 都有) |
| 一个全新邮箱 | 从来没注册过 Claude,也别和旧号邮箱长得像 | 第六步教你在干净环境里建 |
| 付款方式(之后订阅用) | 和旧号**不是同一张卡、同一个支付账号** | 新卡,或美区 Apple ID 礼品卡余额 |

> [!CAUTION]
> **两件事一开始就要知道**:① 被封的旧号**救不回来**,这篇讲的是让新号不被牵连,不是把旧号洗白;② **别买「成品号」**(别人批量注册打包卖的账号),它们大多在被关联的那一串里,常常一登录就被封。稳的办法只有一个:干净环境,自己注册,自己养。

## 先搞懂:平台靠什么认出"还是你"

所谓"关联封号",就是新号在下面这几项上和被封的旧号撞上了。这几项是"**与"的关系,漏一项就前功尽弃**:只换 IP 不换浏览器指纹,一样被关联;浏览器清干净了但 IP 是旧的,照样连坐。

| 维度 | 它记录什么 | 不换会怎样 | 在哪一步处理 |
| --- | --- | --- | --- |
| 出口 IP | 你从哪上网、是不是代理 / 机房 | 用回被标记的旧 IP,直接连坐 | 第一步 |
| 设备指纹(权重最高) | Canvas / WebGL / 字体 / 分辨率 / UA 等拼出的唯一标识 | 同一指纹 = 同一台设备,新号**必被关联**。换 Profile、开无痕都**换不掉** | 第四步 |
| 本地痕迹 | Cookie、缓存、App 和 Claude Code 存的登录凭据 | 残留旧号的痕迹,一登录就被认出 | 第二步 |
| 时区 | 系统 / 浏览器 / App 报出的时区 | 和 IP 地区对不上 = 可疑;来回改更是严重异常 | 第三步 |
| WebRTC / DNS 泄露 | 绕过代理暴露的真实 IP | 前面全白做,真实身份漏出去 | 第四、五步 |
| 邮箱 / 付款 | 注册用的邮箱、绑的卡 | 复用任何一样都会把新旧号串起来 | 第六、七步 |

## 整体流程

① **换 IP**（新段住宅·开 TUN） → ② **清痕迹**（浏览器·App·Code） → ③ **改时区**（跟 IP 一致） → ④ **建环境**（AdsPower 新环境） → ⑤ **自检**（五项全绿） → ⑥⑦ **新身份 + 注册**（环境里完成） → ⑧⑨ **登录 + 养号**（3–5 天再订阅）

*顺序别乱:先把环境弄干净、自检全绿,再碰 claude.ai*

## 第一步:换一条新段住宅 IP,并打开 TUN

#### 1. 换掉被封时用的 IP

被封时用的那条出口八成已经被标记了,而且**同一段的 IP 大多同命**。所以要换的是**不同 IP 段**的住宅 IP,不是同段换一个。找你的 IP 服务商换到别的段,换好后在客户端里刷新一次订阅。

#### 2. 客户端打开 TUN(虚拟网卡)

在 Clash Verge / FlClash 里打开 **TUN / 虚拟网卡**,出站模式选**规则**。**只开「系统代理」不够**:桌面 App、Claude Code、指纹浏览器都不一定走系统代理,只有 TUN 能把它们全部接管。这一整篇的操作,客户端都要一直开着 TUN。

#### 3. 确认新 IP

用平时的浏览器打开 `ippure.com`,看三项:类型 **Residential(住宅)**、风险分**绿色(0–25)**、地区**美国**。顺便**记下它显示的城市**,第三步改时区要用。

| 项目 | 说明 |
| --- | --- |
| IP 类型 | Residential 住宅 ✓ |
| 风险分 | 10 / 100　绿色 ✓ |
| 所在地 | United States · New York(记下这个城市) |
| 与旧 IP | 不同段 ✓ |

*图 1:换 IP 后 ippure.com 这几项要全绿,且和旧 IP 不同段*

## 第二步:清掉旧号留在这台设备上的所有痕迹

你登过旧号的地方,都会留下登录凭据和设备标识:浏览器、Claude 桌面 App、Claude Code、手机 App。**按下面的顺序清**,只清你用过的那几项即可。

> [!WARNING]
> 下面删配置会清掉这台设备上**所有** Claude 的登录和设置(不止被封的那个号)。里面还有想留的账号或 Claude Code 设置,先记好再删。

### 2.1 手机 App(装过的才需要)

#### 1. 退出登录,删除 App

先在 Claude App 里**退出登录**,再删掉它。**iPhone / iPad**:长按 Claude 图标 → 删除 App → 删除。**安卓**:设置 → 应用 → Claude → 存储 → 先点「清除数据 / 清除缓存」,再卸载。

#### 2. 重启一下手机,先别重装

等新号注册好(第七步)再装回来,用新号登录。手机上的时区和代理设置在第三步一起讲。

### 2.2 日常浏览器

新号以后只在第四步的指纹浏览器环境里用,日常浏览器**不会再登这个新号**。所以这里清的是旧号在日常浏览器里的残留,防止你以后误点、误登时把两边带到一起:

#### 1. 删掉 claude.ai 和 anthropic.com 的站点数据

**Chrome**:地址栏输入 `chrome://settings/content/all` 回车 → 右上角搜 `claude` → 点删除图标;再搜 `anthropic` 删一次。**Edge**:地址栏输入 `edge://settings/siteData` 回车 → 搜 `claude`、`anthropic` → 删除。

#### 2. 退出 claude.ai 上的登录

清完再打开 claude.ai 应该是未登录状态。以后日常浏览器里**不要再登任何 Claude 账号**。

> *示意界面（浏览器 · 隐私和安全 · 网站数据）*：
>
> 删除 claude.ai / anthropic.com 的数据
>
> | 项目 | 说明 |
> | --- | --- |
> | Cookie | 删除 ✓ |
> | 缓存文件 | 删除 ✓ |
> | localStorage / IndexedDB | 删除 ✓ |
>
> 删除

*图 2:把这两个站点的本地数据全删掉(示意)*

### 2.3 Claude 桌面 App(装过的才需要)

#### 1. 退出登录并卸载

先在 Claude 里**退出登录**。**Windows**:设置 → 应用 → 已安装的应用 → Claude → 卸载。**Mac**:访达 → 应用程序 → 把 Claude 拖到废纸篓。

#### 2. 删掉它的数据文件夹

**Windows**:文件资源管理器地址栏输入 `%APPDATA%` 回车 → 删掉 **Claude** 文件夹。**Mac**:访达 → 前往 → 前往文件夹 → 输入 `~/Library/Application Support/Claude` → 删掉这个文件夹,再清空废纸篓。

#### 3. 先别重装

等新号注册好,第八步再装,用新号登录。

### 2.4 Claude Code(用过命令行版的才需要)

Claude Code 把登录凭据和设备信息存在用户目录下的 `.claude` 文件夹和 `.claude.json` 文件里,**删掉它们才算真正重置**。桌面 App 也会往 `.claude` 里写东西,所以要**先做完 2.3** 再删,不然它会被重新建出来。

**Mac / Linux**:打开「终端」,依次运行:

```bash
# 1. 卸载程序(用官方安装器装的)
rm -f ~/.local/bin/claude
rm -rf ~/.local/share/claude
# 以前用 npm 装的,改运行这一行:
npm uninstall -g @anthropic-ai/claude-code

# 2. 删登录凭据和设置(关键)
rm -rf ~/.claude
rm -f ~/.claude.json
```

**Windows**:打开 **PowerShell**,依次运行:

```bash
# 1. 卸载程序(用官方安装器装的)
Remove-Item -Path "$env:USERPROFILE\.local\bin\claude.exe" -Force
Remove-Item -Path "$env:USERPROFILE\.local\share\claude" -Recurse -Force
# 以前用 npm 装的,改运行这一行:
npm uninstall -g @anthropic-ai/claude-code

# 2. 删登录凭据和设置(关键)
Remove-Item -Path "$env:USERPROFILE\.claude" -Recurse -Force
Remove-Item -Path "$env:USERPROFILE\.claude.json" -Force
```

提示"找不到路径"说明本来就没有,忽略即可。删完在终端输入 `claude`,提示"找不到命令"就说明卸干净了;如果还能运行,说明电脑上还有另一份(比如以前用 Homebrew 或 npm 装的),把那份也卸掉。

## 第三步:把时区改成和 IP 一致

美国 IP 配一个北京时区,平台一看就知道不对。**只改时区,语言不用改**(海外华人用中文系统很正常)。

### 改成哪个时区?看第一步记下的城市

| ippure.com 显示的城市 | Windows 里选 | Mac / 手机里搜城市 |
| --- | --- | --- |
| New York、Boston 等东部城市 | (UTC−05:00) 东部时间(美国和加拿大) | New York(纽约) |
| Dallas、Austin、Houston、Chicago 等中部城市 | (UTC−06:00) 中部时间(美国和加拿大) | Dallas / Chicago |
| Los Angeles、Seattle 等西部城市 | (UTC−08:00) 太平洋时间(美国和加拿大) | Los Angeles(洛杉矶) |

### 哪些地方要改?

第四步的指纹浏览器会让**它自己那个环境**的时区自动跟随 IP,但它管不到电脑上的其他程序:

| 你会怎么用 Claude | 它读的时区 | 系统时区要不要改 |
| --- | --- | --- |
| 只在指纹浏览器里用网页版 | 环境自己的设置 | 【可以不改】 |
| Claude 桌面 App | **电脑系统时区** | 【必须改】 |
| Claude Code(命令行) | **电脑系统时区** | 【必须改】 |
| 手机 Claude App | **手机系统时区** | 【必须改】 |

#### 1. Windows

设置 → 时间和语言 → 日期和时间 → 关闭「**自动设置时区**」→ 在「时区」里手动选上表对应的那一项。

#### 2. Mac

系统设置 → 通用 → 日期与时间 → 关闭「**使用你的当前位置自动设定时区**」→ 在「最近的城市」里搜上表对应的城市。

#### 3. iPhone / iPad

设置 → 通用 → 日期与时间 → 关闭「自动设置」→ 点「时区」,**搜城市名**(输 New York,不是搜"东部时间")。

#### 4. 安卓

设置 → 系统 → 日期和时间 → 关闭「自动设置时区」→ 手动选。小米 / 华为在「系统和更新」下面,各家路径略有不同。

> [!CAUTION]
> **时区一旦改成美区,就别再改回去**!平台会持续记录你的时区,一会儿美国、一会儿北京是严重的异常,比一直不改还危险。改完会影响电脑右下角、手机闹钟和微信里的时间显示,这是正常的,习惯一下就好。**受不了手机改时区的**,那就别在手机上用这个号,只在电脑上用。

> [!TIP]
> **手机上还有一件比时区更要紧的事:Claude App 的流量有没有真的走代理**。手机浏览器打开 ippure.com 显示美国,只能证明浏览器走了代理,证明不了 App。用的时候打开代理软件的「连接 / Connections」列表,搜 `claude` 或 `anthropic`,**能看到记录才算数**;拿不准就开全局模式。另外,下载 App 用的 Apple ID / Google 账号最好是美区。

## 第四步:用 AdsPower 建一个全新的干净环境(最关键的一步)

这一步最容易做半套。光清 Cookie 完全不够:Canvas / WebGL / 字体这些拼出来的"设备指纹"不换,你在平台眼里**还是同一台机器**,而且被封过的号,指纹这条线索的分量比 IP 还重。先看清几种做法的差距:

| 做法 | Cookie | 设备指纹 | 能不能单独挂 IP | 结论 |
| --- | --- | --- | --- | --- |
| 无痕 / 隐私窗口 | ✓ 不留 | ✗ **完全没变** | ✗ | 【没用】 |
| 新建 Chrome Profile | ✓ 隔离 | ✗ **还是同一张脸** | ✗ 只能跟系统代理 | 【被封过的不够用】 |
| **指纹浏览器(AdsPower 等)** | ✓ 隔离 | ✓ **每个环境一套** | ✓ 一环境一 IP | 【推荐】 |
| 换一台干净的设备 | ✓ | ✓ 物理级最彻底 | ✓ | 【最稳但成本高】 |

**这个环境就是新号以后唯一的入口**:网页版在这里用;桌面 App 和 Claude Code 登录时要收的邮件、要点的授权页,也都在这里打开。下面以 AdsPower 为例,比特浏览器、HubStudio 的设置项名字略有不同,思路完全一样。

### 4.1 安装并新建环境

#### 1. 下载安装 AdsPower,注册登录

到 AdsPower 官网下载对应系统的客户端,注册一个账号登录。免费版的环境数量够个人用。

#### 2. 点「新建浏览器」,起个能认出来的名字

比如 **Claude-新号**。**如果以前给旧号建过环境,别沿用那个**,要新建一个。新环境会自动生成一套独立的指纹,平台和其他选项保持默认。

### 4.2 把新 IP 接进环境(两种方式选一种)

|  | 方式一:本地直连(推荐,大多数人选这个) | 方式二:独享 socks5 |
| --- | --- | --- |
| 适合谁 | 只有一个号 | 要同时养多个号,一个号一个 IP |
| 出口 IP | 就是你代理订阅里的住宅 IP | 每个环境一个独立住宅 IP |
| 前提 | 代理客户端开着 **TUN** | 另外开通独享 socks5,同样建议开着 TUN |

#### A. 方式一:本地直连

确认 代理客户端开着 TUN(第一步),在新建环境的「**代理设置**」里选 **不使用代理**(有的版本叫**本地直连 / No Proxy**)。主机、端口、账号密码**都不用填**。这样环境里的流量会被 TUN 接管,出口就是你的住宅 IP。

#### B. 方式二:独享 socks5

代理方式选「自定义」,代理类型选 **SOCKS5**(别选 HTTP),把我们发你的**主机、端口、用户名、密码**四项依次填进去。主机栏只填地址本身,前面别加 `http://`。填完点「**检测代理**」,要显示连接成功、国家美国。

> [!CAUTION]
> **必须开 TUN,只开「系统代理」不行**。指纹浏览器不一定走系统代理,只开系统代理时它可能直接用国内网络出去,环境里看到的就是你的真实国内 IP。**方式二点「检测代理」不通过,九成也是这个原因**:AdsPower 是自己去连 socks5 的,不经过 Clash,在国内直接连境外地址连不上;打开 TUN 再点检测就通了。以后每次打开这个环境前,都先确认 代理客户端和 TUN 开着。

### 4.3 三个设置一定要改对

#### 1. 时区:打开「基于 IP 匹配时区」

环境的时区会自动跟着出口 IP 走。这只管这个环境,电脑系统时区按第三步的表决定要不要改。

#### 2. WebRTC:选「禁用」

在指纹设置里找到 **WebRTC**,选**禁用**,**别选「真实」**。WebRTC 会绕过代理直接向外发包,选「真实」时网页能读到你本机的真实 IP,新 IP、新指纹等于白换。禁用后用 Claude 聊天、上传文件都不受影响。

#### 3. 指纹:保持默认,别开「随机指纹」

AdsPower 默认给每个环境生成一套固定的指纹,保持默认就好。**千万别开"每次启动随机指纹**":真实设备的指纹不会变,天天变反而更可疑。

> *示意界面（AdsPower · 新建浏览器）*：
>
> Claude-新号
>
> | 项目 | 说明 |
> | --- | --- |
> | 代理设置 | 不使用代理(本地直连)✓ / 或 SOCKS5 |
> | 时区 | 基于 IP 匹配 ✓ |
> | WebRTC | 禁用 ✓ |
> | 随机指纹 | 关闭 ✓ |
>
> 确定

*图 3:新建环境时要改对的四项(示意,不同版本名称略有不同)*

### 4.4 环境的使用规矩(以后一直遵守)

- **一个环境只登一个 Claude 号**,也只登这个号对应的那一个邮箱。
- **环境和 IP 长期绑死**,别换来换去;也**别删掉环境重建**,那等于换了一台新设备。
- 这个号**只在这个环境里用**,日常浏览器里永远不登。

## 第五步:注册前自检,五项全绿再继续

**在 AdsPower 环境窗口里**(不是日常浏览器)打开 `ippure.com`,逐项核对:

| 项目 | 说明 |
| --- | --- |
| IP 类型 | Residential 住宅 ✓ |
| 风险分 | 绿色(0–25)✓ |
| 所在地 | United States,和第一步看到的一致 ✓ |
| 时区 | 和 IP 所在地一致 ✓ |
| DNS / WebRTC | 无泄露 ✓ |

*图 4:这五项全绿,才开始注册*

哪一项不对,按下表处理,处理完再测一遍:

| 看到的问题 | 原因 | 怎么办 |
| --- | --- | --- |
| 显示中国 IP,或和第一步看到的不一样 | 环境没走代理 | 确认 代理客户端和 **TUN** 开着;方式二检查四个参数 |
| 类型不是 Residential,或风险分黄 / 红 | 这个 IP 不干净 | 换一条干净的 IP,别硬用 |
| 时区和 IP 对不上 | 没开「基于 IP 匹配时区」 | 回 4.3 打开,重启环境 |
| WebRTC 显示真实 IP 或内网地址 | WebRTC 没禁用 | 回 4.3 改成「禁用」 |
| DNS 显示国内运营商 / 国内 DNS | DNS 没跟着代理走 | 确认用的是我们发的订阅(不是裸节点),客户端里关掉 IPv6 |

想再多测一遍 DNS:在环境里打开 `dnsleaktest.com` 点 Standard test,结果里不应该出现中国的运营商。

## 第六步:在环境里准备一个全新邮箱

邮箱是新号的身份,也是以后每次登录收验证邮件的地方,所以它也要在这个干净环境里建、在这个环境里用。

#### 1. 在环境窗口里注册新邮箱

在 AdsPower 环境窗口里打开 `outlook.com` 或 `accounts.google.com` 注册一个新邮箱。用户名随便起,**别和旧号邮箱长得像**;填英文姓名,按提示完成验证。Outlook 对网络要求低一点,更容易注册成功。

#### 2. 保持邮箱在这个环境里登录着

以后 Claude 的登录邮件、验证码都在这个环境的邮箱标签页里收。**不要在手机邮箱 App 或日常浏览器里点 Claude 的登录链接**:链接在哪个浏览器里点开,Claude 就登录在哪个浏览器上。

| 身份信息 | 要求 |
| --- | --- |
| 邮箱 | 全新、没注册过 Claude,别用旧号那个,也别用相似规律的 |
| 姓名 | 不必和旧号一样,填一个正常的英文名即可 |
| 付款方式 | 以后订阅时用新卡 / 新支付账号,**一张卡只绑一个号**(第九步再说) |

## 第七步:在环境里注册新号

全程在同一个 AdsPower 环境窗口里做,**中途别切网络、别切节点、别登任何旧账号**。

#### 1. 打开 claude.ai,选邮箱注册

在环境窗口里打开 `claude.ai` → 在邮箱框里输入新邮箱 → 点 **Continue with email**。**不要点「Continue with Google / 使用 Google 登录」**:它很容易跳回你电脑的默认浏览器,那里是你的真实指纹,前面的隔离就白做了。

#### 2. 在同一窗口的邮箱里收信

切到环境里的邮箱标签页,打开 Claude 发来的邮件(没看到翻一下垃圾邮件,别连续点重发)。邮件里是登录按钮就**在这个窗口里点**;是验证码就复制回 claude.ai 填进去。

#### 3. 填写资料,完成注册

填名字、勾选条款,点 Continue,完成注册。

> *示意界面（AdsPower 环境窗口 · claude.ai）*：
>
> Sign up
>
> | 项目 | 说明 |
> | --- | --- |
> | Email | (你的新邮箱) |
> | Continue with email | 点这个 ✓ |
> | Continue with Google | ✗ 不要点 |

*图 5:注册和以后每次登录,都用邮箱方式(示意)*

| 注册时遇到 | 多半是因为 | 怎么办 |
| --- | --- | --- |
| 提示 unable to create your account(无法创建账户) | 这个 IP 或整段被判高风险 | 停下来,换一条不同段的干净 IP,换完回第五步重新自检 |
| 人机验证怎么点都过不去 / 提示地区不可用 | IP 信誉低 | 同上,别反复硬试 |
| 收不到验证邮件 | 邮件进了垃圾箱或有延迟 | 翻垃圾邮件,等一两分钟,别连续点重发 |
| 刚注册就被封 | 还有一层没清干净 | 按页面最后的「检查清单」逐项对,尤其是指纹和 IP 段 |

## 第八步:桌面 App 和 Claude Code 也用新号登录

**网页版**以后每次登录都和第七步一样:在 AdsPower 环境里打开 claude.ai → 输入邮箱 → Continue with email → 在环境的邮箱里收信点登录。只用网页版的,这一步后面可以跳过。

桌面 App 和 Claude Code 是装在电脑上的独立程序,不在指纹浏览器里,所以要做到三点:**开着 TUN、系统时区已经改成美区(第三步)、登录邮件和授权页在 AdsPower 环境里打开**。

### 8.1 Claude 桌面 App

#### 1. 重新安装

在 AdsPower 环境窗口里打开 `claude.ai/download` 下载安装包,装好后打开。

#### 2. 输入邮箱,点 Continue with email

同样只用邮箱方式。如果它自动弹开了你的默认浏览器(Chrome / Edge / Safari),**别在里面登录**,直接关掉那个页面。

#### 3. 回 AdsPower 环境的邮箱里收信

邮件里有**验证码**:复制回桌面 App 填进去。邮件里只有**登录按钮**:在环境窗口里点它,浏览器问「要打开 Claude 吗?」时点允许,桌面 App 就自动登录了。

### 8.2 Claude Code(命令行)

#### 1. 重新安装

**Mac** 在终端运行 `curl -fsSL https://claude.ai/install.sh | bash`;**Windows** 在 PowerShell 运行 `irm https://claude.ai/install.ps1 | iex`。Claude Code **不支持 socks5**,也不一定走系统代理,一定要靠 TUN。

#### 2. 运行 claude,选订阅账号登录

在终端输入 `claude`,登录方式选 **Claude account with subscription**。它会尝试自动打开你的默认浏览器,**直接关掉那个页面**,别在那里授权。

#### 3. 把授权链接拿到环境里打开

终端里会打印一串以 `https://claude.ai/oauth/authorize?` 开头的长链接,**完整复制**,粘到 AdsPower 环境窗口的地址栏打开。这个环境已经登着新号,点 **Authorize / 授权**。

#### 4. 授权码粘回终端

页面会显示一串授权码,复制它回到终端粘贴、回车,看到登录成功就好了。有的版本点完授权会自动完成,不需要再粘。

```bash
$ claude
# 选择 Claude account with subscription
Browser didn't open?
Use the url below to sign in:
https://claude.ai/oauth/authorize?……
# ↑ 整串复制,粘到 AdsPower 环境窗口打开,点授权

Paste code here if prompted >
# ↑ 把授权码粘到这里,回车
```

### 8.3 手机 App(要在手机上用的)

先按第三步把手机时区改好、确认 Claude App 的流量走了代理,再到 App Store / Play 商店重新下载 Claude,用新邮箱登录。登录邮件同样尽量回到 AdsPower 环境里打开,把里面的验证码填到手机上,别直接在手机邮箱里点登录链接。

## 第九步:注册后先养号,再订阅

> [!CAUTION]
> **新号先养 3–5 天再订阅,别注册当天就付费**。环境再干净,一个全新账号当天就掏钱,"太新 + 行为太完美"反而会被判异常。先用免费额度正常聊几天:每天登录,随便问几句,别一上来就猛用、跑脚本。

### 订阅时

- **一张卡只绑一个号**,别用旧号付过款的卡;一卡多号会把这些号连成一串,一个出事全部连坐。
- **有美国信用卡的,直接在官网订阅**:登录后右下角头像 → Settings → Plans,选 Pro / Max。
- **没有美国信用卡的**,以前常用「美区 Apple ID + 礼品卡余额」在 iPhone 的 Claude App 里订阅。**但 2026 年 11 月起这条路明显变难了**:只靠礼品卡余额、没有绑定付款方式的 Apple ID,经常**付款直接被拒**,或**付款后被要求做身份验证(KYC)**。还想走这条路的,先用最小面额试通再加量;遇到被拒别反复重试,被要求验证时**别提交别人的证件或编造的资料**(查出来 Apple ID 会被永久锁定,余额一起没)。完整步骤和处理办法见 [Claude 苹果礼品卡订阅全流程](claude-subscription.md),卡住了[加群交流](https://claucc.net/contact)。
- 虚拟卡、来路不明的卡风险分低,尽量别用。

### 日常使用的红线

- 一个账号**别多人、多地同时登录**,这是最常见的封号原因。
- **固定同一个住宅 IP**,别频繁切节点,真实用户不会天天换城市。
- 电脑上用这个号时,**代理客户端和 TUN 一直开着**;客户端没开的时候别打开这个环境、别用桌面 App 和 Claude Code。
- 时区改了就别改回去;环境别删了重建;别开随机指纹。
- 每个月在环境里打开 ippure.com 抽查一次,风险分变高了换一条 IP。

## 常见问题

- **不想用指纹浏览器,能不能凑合**?只是临时重注一个号的,至少做到:换一个**平时不用的浏览器**(比如日常用 Chrome,就用 Firefox 专门跑这个号,不同内核的指纹差异比换 Profile 大得多);别登录浏览器的 Google / 微软同步;Chrome 设置 → 隐私和安全 → 安全 → 关掉「使用安全 DNS」;装「WebRTC Leak Shield」扩展堵 WebRTC 泄露;系统时区必须改。但要清楚:**指纹没换,被封过的设备风险明显更高**,能上指纹浏览器还是上。
- **被封的旧号能救回来吗**?Disabled 基本是永久封禁,几乎救不回;Suspended 是临时封禁,可以通过官方支持渠道如实申诉,结果看个案。不管能不能救,都**别在新环境里登旧号**去试。
- **不小心在日常浏览器或手机上点了登录链接**?在那个浏览器里退出 Claude,回到 AdsPower 环境重新走一遍邮箱登录。之后别再这样。
- **授权页打不开、一直转圈**?先在同一个环境窗口里确认能打开 claude.ai;打不开就检查 代理客户端和 TUN 是否开着。
- **以前一直用 Google 快捷登录,改成邮箱登录会变成新号吗**?不会。输入同一个邮箱地址就是同一个账号,对话和订阅都在。
- **要同时用好几个号**?一个号一个 AdsPower 环境,每个环境各用一个独享 socks5(4.2 的方式二),每个号各用一张卡。多个号共用一个出口 IP 等于把它们串在一起。
- **Mac 和 Windows 都要用这个号**?可以,每台电脑都按第二、三步清痕迹、改时区,并用同一个出口 IP;别两台电脑在不同地方同时登录。

## 最后一遍检查清单

注册前、以及新号出问题时,逐行对一遍:

| 项目 | 做到了吗 |
| --- | --- |
| 换了**不同段**的住宅 IP,ippure.com 显示住宅、绿色、美国 | ☐ |
| 代理客户端开着 **TUN**(不是只开系统代理) | ☐ |
| 手机、浏览器、桌面 App、Claude Code 的旧号痕迹都清了(用过的那几项) | ☐ |
| 系统时区改成和 IP 同城的美区时区,并且不再改回 | ☐ |
| AdsPower **新建**了环境:时区跟随 IP、WebRTC 禁用、没开随机指纹 | ☐ |
| 环境里 ippure.com 五项全绿 | ☐ |
| 新邮箱,并且在环境里登录着 | ☐ |
| 注册和登录都用 Continue with email,邮件在环境里打开 | ☐ |
| 桌面 App / Claude Code 的授权在环境里完成 | ☐ |
| 养号 3–5 天再订阅,一张卡只绑这一个号 | ☐ |

【原样直接重注(很快又被封)】

- 旧 IP + 旧设备指纹 + 残留的登录凭据
- 旧邮箱 / 同一张卡
- → 新号被关联到被封的旧号

【清干净再注册(稳)】

- 新段住宅 IP + 指纹浏览器新环境 + 零残留
- 新邮箱 / 新支付
- 时区跟随 IP、无泄露 → 平台看到的是一个全新的真人
- 养 3–5 天再订阅
